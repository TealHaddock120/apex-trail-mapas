# Mapas de Apex Trail

Mapa de México sin conexión que descarga la app Apex Trail.

- Archivo: `mexico.pmtiles` (formato PMTiles, nivel de detalle 14, incluye brechas y veredas).
- Datos: © colaboradores de OpenStreetMap, disponibles bajo la licencia Open Database License (ODbL).
- Generado a partir del mapa base de Protomaps (https://protomaps.com).

Cada versión del mapa es una "release"; la app lee `mapa.json` de la más reciente.
